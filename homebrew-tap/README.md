# homebrew-backbeatin

This is the Homebrew tap for Backbeatin, a backup verification tool.

## Installation

```bash
brew tap eniyos/backbeatin
brew install backbeatin
```

## Documentation

For full documentation, see [https://github.com/eniyos/backbeatin](https://github.com/eniyos/backbeatin)
